감사 로그 이벤트

Agentic 코드 보안은 사용자·시스템 작업을 Microsoft Purview 통합 감사 로그에 기록합니다. 활동 모니터링·사고 조사·규정 준수에 활용합니다.

감사되는 작업

모든 레코드는 Workload MicrosoftSecurityExposureManagement, RecordType 500을 사용합니다.

작업설명
ConnectedFoundryResourceFoundry 리소스를 연결·업데이트. 자격 증명 생성·업데이트 시 기록(성공·실패 모두).
DisconnectedFoundryResourceFoundry 자격 증명 삭제. 삭제 시도 시 기록(성공·실패·no-op 포함).
StartedCodeScan스캔 제출 수락. S2S SubmitScan 수락 시(CDT 전용).
UploadedScanResults결과가 시스템 경계 진입(SARIF blob·AI 스캔 결과 수락). 소스코드 포함 시 ContainsCodeSnippet=true.
ViewedScanResults읽기 엔드포인트가 스캔·발견 데이터 반환. 개별 발견 반환 시 true, 집계·목록 뷰는 false.
