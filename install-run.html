Defender CLI 설치 및 실행

터미널에서 Defender CLI를 내려받아 에이전트 코드 스캔을 실행합니다. CLI는 저장소의 로컬 복사본을 스캔합니다.

사전 요구사항

  • Defender CLI 인증 완료 (Defender CLI 설정).
  • 스캔할 저장소의 로컬 clone.

설치

Windows

Invoke-WebRequest `
    -Uri "https://cli.dfd.security.azure.com/public/v2/latest/Defender_win-x64.exe" `
    -OutFile "defender.exe"

Linux / macOS

# Linux (x64)
curl -fL -o defender \
  "https://cli.dfd.security.azure.com/public/v2/latest/Defender_linux-x64"
chmod +x defender

# macOS (Apple Silicon)
curl -fLo Defender https://cli.dfd.security.azure.com/public/v2/latest/Defender_osx-arm64
chmod +x Defender
xattr -d com.apple.quarantine Defender 2>/dev/null || true

그 밖에 Linux arm64, macOS Intel(osx-x64) 바이너리도 같은 경로에서 제공됩니다.

스캔

제출과 결과 대기를 한 명령으로:

defender.exe scan ai-scan submit <TARGET_SOURCE_DIRECTORY>

코드를 제출하고 결과를 대기합니다. 완료되면 결과가 대상 디렉터리에 다운로드되고 Defender 포털에서도 확인 가능합니다.

스캔 프로파일 (Preview)

스캔 프로파일은 어떤 AI 모델로 스캔할지 선택합니다.

프로파일모델사용 시점
gpt-general-profileGPT-5.4, GPT-5.3-Codex, GPT-5.4-Mini범용 에이전트 코드 스캐닝(기본 모델 세트).
mai-augmented-profile Preview위 3종 + MAI-Cyber-1-Flash기본 모델을 사이버 특화 MAI-Cyber-1-Flash로 보강하고 싶을 때.
# 사용 가능한 프로파일·기본값 확인
defender scan profile model list
defender scan profile model show-default

# 특정 프로파일로 이번 스캔만 실행 (기본값 override)
defender scan ai-scan submit . --model-profile gpt-general-profile
defender scan ai-scan submit . --model-profile mai-augmented-profile

비동기 워크플로 (장시간 스캔)

# 1) 제출 후 Job ID 받기
defender.exe scan ai-scan submit .
# 출력: Job submitted: <JOB_ID>

# 2) Job 상태 확인
defender.exe status <JOB_ID>

# 3) (선택) 완료 대기 후 결과 다운로드
defender.exe status wait <JOB_ID> -o results.sarif

심각도 필터 / Job 관리

defender.exe scan ai-scan submit . --severity high   # High·Critical만

defender.exe status                    # 추적 중인 모든 Job
defender.exe status result <JOB_ID>    # 완료된 리포트 다운로드
defender.exe status log <JOB_ID>       # 자동 저장된 디버그 로그 경로 출력
defender.exe status cancel <JOB_ID>    # 실행 중 Job 취소
취소 시 토큰 환불 없음 스캔 중 MDASH는 실시간 LLM 호출로 토큰을 소비합니다. 실행 중인 스캔을 취소하면 새 작업 스케줄링은 멈추지만, 취소 이전에 소비된 토큰은 청구됩니다. 취소는 향후 작업의 추가 소비를 막을 뿐, 이미 사용된 토큰을 환불하지 않습니다.
