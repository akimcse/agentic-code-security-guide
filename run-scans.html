스캔 실행

포털에서 원격 On-demand 스캔을 트리거하거나, Defender CLI로 로컬·CI/CD 스캔을 실행하고, 발견된 취약점을 defender fix로 자동 수정하는 방법을 다룹니다.

1. On-demand 에이전트 스캔 트리거 (포털)

GitHub 커넥터가 활성화되면 온보딩된 저장소에 대해 원격 On-demand 스캔을 실행할 수 있습니다(활성화 후 최대 1시간 후 사용 가능).

사전 요구: 생성·활성화된 GitHub 커넥터.

  1. Manage scans 열기 — Defender 포털 > Exposure management > Initiatives → Codename MDASH - Agentic code scanner (preview) 이니셔티브 → Open initiative page → Manage scans 버튼(Settings 옆).
  2. 저장소 목록 확인 — 활성화된 SCM 커넥터로 발견된 모든 저장소가 측면 패널에 표시됩니다.
  3. 저장소 선택 후 스캔 실행 — 저장소 선택 → Start scan → 대화 상자에서 확인.

각 저장소에 대해 저장소 이름·크기·조직명·SCM 유형·마지막 스캔 상태·소비 토큰이 표시됩니다. 저장소 크기와 소비 토큰 신호는 스캔 전에 영향도를 예측하는 데 도움이 됩니다. 스캔 시작 시 알림이 뜨고, 새 스캔이 Scans 탭에 나타나 수명 주기를 진행합니다.

2. Defender CLI 설치 및 실행

사전 요구: Defender CLI 인증 완료(CLI 설정 참고).

플랫폼별 바이너리 다운로드

플랫폼다운로드
Windows…/latest/Defender_win-x64.exe
macOS x64 (Intel)…/latest/Defender_osx-x64
macOS ARM64 (Apple Silicon)…/latest/Defender_osx-arm64
Linux x64…/latest/Defender_linux-x64
Linux ARM64…/latest/Defender_linux-arm64

기본 URL: https://cli.dfd.security.azure.com/public/v2/latest/

# Linux
curl -fL -o defender \
  "https://cli.dfd.security.azure.com/public/v2/latest/Defender_linux-x64"
chmod +x defender

# macOS (Apple Silicon)
curl -fLo Defender https://cli.dfd.security.azure.com/public/v2/latest/Defender_osx-arm64
chmod +x Defender
xattr -d com.apple.quarantine Defender 2>/dev/null || true

첫 스캔 실행

Defender CLI는 저장소의 로컬 복사본을 스캔합니다. 스캔할 저장소를 clone하거나 기존 로컬 clone으로 이동한 뒤 실행합니다.

cd /path/to/your/repo
defender scan ai-scan submit .

이 명령은 저장소 코드를 아카이브해 서비스에 제출하고 스캔 완료까지 대기합니다.

비동기 워크플로 (장시간 스캔)

# 1) 제출 후 Job ID 받기
defender scan ai-scan submit .
# 출력: Job submitted: <JOB_ID>

# 2) Job 상태 확인
defender status ai-scan <JOB_ID>

# 3) (선택) 완료 대기 후 결과 다운로드
defender status wait <JOB_ID> -o results.sarif

심각도 임계값 설정 / Job 관리

# High·Critical 결과만 제한
defender scan ai-scan submit . --severity high

defender status                    # 추적 중인 모든 Job 목록
defender status cancel <JOB_ID>     # 실행 중 Job 취소

3. Agentic 코드 취약점 자동 수정

스캔 후 defender fix로 SARIF 결과에서 AI 기반 코드 수정본을 생성합니다.

사전 요구: Defender CLI 설치 · GitHub Copilot CLI 설치 · 최소 1회 스캔으로 얻은 SARIF 결과 파일.

# 특정 SARIF 결과로 수정
defender fix ./defender-aiscan-<JOB_ID>.sarif

# 심각도 임계값 지정 (임계값 이상 모두 포함)
defender fix ./results.sarif --severity low

4. CI/CD 예제 (GitHub Actions)

런타임에 Defender CLI를 다운로드하고, 자격 증명을 환경 변수로 전달하여 파일 시스템 스캔과 AI 스캔 제출을 모두 실행하는 샘플 워크플로입니다. 트리거·경로 범위·시크릿 이름은 저장소 표준에 맞게 조정하세요.

name: Defender ASPM scan
on: [workflow_dispatch]

permissions:
  contents: read
  id-token: write
  security-events: write

jobs:
  scan:
    runs-on: ubuntu-latest
    env:
      DEFENDER_ASPM_TENANT_ID:     ${{ secrets.DEFENDER_ASPM_TENANT_ID }}
      DEFENDER_ASPM_CLIENT_ID:     ${{ secrets.DEFENDER_ASPM_CLIENT_ID }}
      DEFENDER_ASPM_CLIENT_SECRET: ${{ secrets.DEFENDER_ASPM_CLIENT_SECRET }}
    steps:
      - uses: actions/checkout@v4
      - name: Download Defender CLI
        run: |
          curl -fL -o defender \
            "https://cli.dfd.security.azure.net/public/v2/latest/Defender_linux-x64"
          chmod +x defender
      - run: ./defender scan fs .
      - run: ./defender scan ai-scan submit . --force
주의 자격 증명 값을 소스 제어에 커밋하거나 워크플로 로그에 포함하지 마세요. 시크릿은 정기적으로 교체하고 만료 전에 교체해 파이프라인 실패를 방지하세요. 자격 증명 발급·구성은 CLI 설정의 CI/CD 자격 증명 구성을 참고하세요.
