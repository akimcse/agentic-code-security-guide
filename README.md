# Agentic 코드 보안 (Codename MDASH) 한글 가이드

Microsoft Defender의 **Agentic 코드 보안 (Codename MDASH — Agentic code scanner)** 공식 문서를 한글로 요약·정리한 비공식 학습용 HTML 가이드입니다. 공식 Microsoft Learn TOC 구조를 그대로 미러링하여 **문서 1개 = 페이지 1개**로 구성했습니다.

## 🌐 온라인으로 보기

> **https://akimcse.github.io/agentic-code-security-guide/**

## 구성 (공식 TOC 미러링)

| 그룹 | 페이지 | 문서 |
|---|---|---|
| 개요 | `index.html` | Overview |
| 시작하기 | `onboarding.html` | Getting Started with Codename MDASH |
| | `foundry.html` | Connect Microsoft Foundry |
| | `github-connector.html` | Create a GitHub connector |
| | `cli-setup.html` | Defender CLI setup |
| | `faq.html` | Codename MDASH FAQ |
| 스캔 실행 | `trigger-scan.html` | Trigger an on-demand agentic scan |
| | `install-run.html` | Install and run |

| | `cicd.html` | CI/CD Example |

| 결과 검토 | `review-terminal.html` | Review terminal results |
| | `review-portal.html` | Review Exposure Management in Defender portal |
| 참조 | `audit-log.html` | Audit log events |
| | `admin-consent.html` | Microsoft Defender Code admin consent script |

## 특징

- 🌗 **라이트/다크 모드 토글** — 선택은 브라우저에 저장되어 유지됩니다.
- 🧭 **공유 사이드바** — `app.js`가 모든 페이지에 공식 TOC 사이드바를 주입해 일관성 유지.
- 🔗 각 페이지 하단에 원문 Microsoft Learn 문서 링크, 사이드바에 MDASH 공식 발표 블로그 링크 포함.
- 📱 반응형 레이아웃.

## 출처

본 문서는 [Microsoft Learn — Security Exposure Management / Agentic code security](https://learn.microsoft.com/en-us/security-exposure-management/ai-code-security-overview) 공식 문서를 기반으로 한 **비공식** 한글 정리본입니다. Codename MDASH는 현재 프라이빗 프리뷰 단계로 내용이 자주 바뀌므로, 최신·정확한 정보는 항상 원문을 확인하세요.
