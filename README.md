# Agentic 코드 보안 (Codename MDASH) 한글 가이드

Microsoft Defender의 **Agentic 코드 보안 (Codename MDASH — Agentic code scanner)** 공식 문서를 한글로 요약·정리한 비공식 학습용 HTML 가이드입니다.

멀티모델 에이전트 AI 시스템으로 코드 취약점을 기존 정적 분석보다 깊고 정확하게 탐지하는 Microsoft Security Exposure Management 기능을 다룹니다.

## 🌐 온라인으로 보기

> **https://akimcse.github.io/agentic-code-security-guide/**

## 구성

| 페이지 | 내용 |
|---|---|
| `index.html` | 홈 · 개요 (기능 · 4단계 파이프라인 · 언어/리전 지원 · 허용 목록) |
| `get-started.html` | 온보딩 · Microsoft Foundry 연결 · GitHub 커넥터 · Defender CLI 인증 |
| `run-scans.html` | On-demand 스캔 · CLI 설치/실행 · 자동 수정(`defender fix`) · CI/CD |
| `coding-agent.html` | Defender Code Security 스킬 (Copilot CLI / Claude) |
| `results.html` | 터미널 HTML·SARIF 결과 · Defender 포털 MDASH 이니셔티브 |
| `reference.html` | Purview 감사 로그 이벤트 · 관리자 동의 PowerShell 스크립트 |

## 특징

- 🌗 **라이트/다크 모드 토글** — 선택은 브라우저에 저장되어 유지됩니다.
- 📱 반응형 레이아웃, 사이드바 내비게이션
- 🔗 각 페이지 하단에 원문 Microsoft Learn 문서 링크 및 MDASH 공식 발표 블로그 링크 포함
