On-demand 에이전트 스캔 트리거 (포털)

GitHub 커넥터가 활성화되면 온보딩된 저장소에 대해 원격 On-demand 스캔을 실행할 수 있습니다. (활성화 후 최대 1시간 후 사용 가능)

사전 요구사항

  • 생성·활성화된 GitHub 커넥터.

1단계: Manage scans 열기

  1. Defender 포털 > Exposure management > Initiatives.
  2. Codename MDASH - Agentic code scanner (preview) 이니셔티브 → Open initiative page.
  3. Manage scans 버튼 선택 (Settings 옆).

2단계: 저장소 목록 확인

측면 패널에 활성화된 SCM 커넥터로 발견된 모든 저장소가 표시됩니다. 각 저장소별로:

  • 저장소 이름 · 저장소 크기 · 조직명
  • SCM 유형 (Source Control Management 플랫폼 종류, 예: GitHub)
  • 스캔 상태 — 마지막 스캔 · 마지막 스캔의 소비 토큰

저장소 크기와 소비 토큰 신호는 스캔 전에 영향도를 예측하는 데 도움이 됩니다.

3단계: 저장소 선택 후 스캔 실행

  1. 스캔할 저장소 선택.
  2. Start scan 선택.
  3. 나타나는 대화 상자에서 확인.
큐 제한 테넌트에 포털·CLI를 합쳐 이미 10개의 대기(queued) 스캔이 있으면 경고가 표시됩니다. 그래도 제출은 가능합니다. 제출 후 72시간 내에 실행이 시작되지 않은 대기 스캔은 자동 정리되므로 일부 대기 스캔은 실행되지 않을 수 있습니다.

스캔 시작 시 알림이 뜨고, 새 스캔이 Scans 탭에 나타나 수명주기를 진행합니다.
