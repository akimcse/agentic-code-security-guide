터미널 결과 검토

스캔이 완료되면 Defender CLI가 스캔을 시작한 디렉터리에 결과 파일을 자동 생성합니다. 사람용 HTML 리포트와 도구 연동용 SARIF, 두 형식이 제공됩니다.

사전 요구사항

  • Defender CLI 설치·인증 (CLI 설정).
  • Defender 통합 RBAC의 Scan results (Read) 권한.
  • 완료된 AI 스캔: defender scan ai-scan wait <JOB_ID>

결과 파일

형식적합한 용도
HTML 리포트사람 검토 — 발견·심각도·영향 코드 경로·권장 수정의 시각적 요약.
SARIF 파일프로그래밍적 처리 — CI/CD 통합, 보안 대시보드 임포트, 커스텀 리포팅.

HTML 리포트

스캔 디렉터리로 이동해 생성된 .html을 브라우저에서 엽니다. 포함 내용:

  • 발견 요약 — 심각도별(Critical·Important·Moderate·Low) 총계.
  • 심각도 분석 — CWE 분류·심각도·검증 단계 신뢰도 점수.
  • 영향 코드 경로 — 파일 경로·라인·코드 스니펫.
  • 권장 수정 — 항목별 AI 생성 수정 제안.

SARIF 파일 (v2.1.0)

OASIS SARIF v2.1.0 사양을 따르는 기계 판독 결과로 업계 표준 도구와 호환됩니다. 용도: CI/CD 임포트(GitHub Advanced Security·Azure DevOps PR 주석), SIEM·보안 자세 도구 공급, 커스텀 리포트, 스캔 간 비교로 수정 속도 추적.

섹션설명
runs[].results[]규칙 ID·심각도·메시지·위치를 포함한 개별 발견 배열.
runs[].tool스캐닝 하네스 버전·구성 메타데이터.
runs[].results[].locations[]각 발견의 물리·논리 위치(파일 경로·라인·컬럼).
runs[].results[].codeFlows[]취약점 도달 경로의 단계별 실행 흐름(prove 단계에서 가능할 때).
# 완료된 스캔 결과 다운로드
defender status wait <JOB_ID> -o results.sarif
