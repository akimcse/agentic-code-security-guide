온보딩

권한 설정(RBAC)과 Foundry 설정을 마친 뒤, Defender 포털에서 이니셔티브 진입점으로 온보딩 플로우를 시작해 약관을 수락하고, Foundry에서 확보한 Project endpoint·API key를 입력해 Validate → Save로 온보딩을 완료합니다. 전체 흐름은 개요를 참고하세요.

1. 진입점(Entry points)

Defender 포털에서 다음 위치 중 하나로 온보딩 플로우를 시작합니다.

  • Exposure Management > Overview → Agentic code security 선택
  • Exposure Management > Initiatives → Codename MDASH - Agentic code scanner 이니셔티브 선택

2. 약관 수락

진입점에서 온보딩 플로우를 시작하면 약관을 검토하고 체크박스로 수락합니다. 약관을 수락해야 이후 Save가 활성화됩니다.

3. 엔드포인트 입력 → 검증 → 저장

Foundry 설정에서 복사해 둔 값을 온보딩 창에 입력합니다.

  1. Project endpoint(예: https://your-foundry.azure.com)와 API key를 입력합니다.
  2. Validate를 눌러 연결을 검증합니다. (검증에 성공해야 저장할 수 있습니다.)
  3. Save로 온보딩을 완료합니다. (약관을 수락해야 Save가 활성화됩니다.)
참고 저장 후 실제 스캔을 실행하려면 GitHub 커넥터(원격, 권장) 또는 Defender CLI 경로를 구성해야 합니다. GitHub 커넥터는 이 온보딩 전후 어느 시점에 만들어도 됩니다.
⚠️ 셋업 창이 뜨지 않거나 Validate가 실패하나요? Foundry 설정을 마쳤는데도 엔드포인트·키 입력 셋업 창이 안 뜨거나 Validate가 실패하는 경우가 있습니다. 트러블슈팅의 해당 항목(브라우저는 Microsoft Edge 사용, Foundry 방화벽 IP 허용)을 확인하세요.
