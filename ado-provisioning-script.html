ADO 커넥터 프로비저닝 스크립트

Grant-DefenderConsent.ps1 PowerShell 스크립트로 Microsoft Defender Code 서비스 주체를 프로비저닝하고, Azure DevOps 커넥터에 필요한 테넌트 전역 관리자 동의를 부여합니다. Microsoft 365 E5 라이선스가 없거나 ADO 조직 테넌트가 Defender 테넌트와 다른 경우, 커넥터 생성 전에 이 스크립트를 실행합니다.

GitHub/CLI 경로와 구분 이 스크립트(Grant-DefenderConsent.ps1)는 Azure DevOps 커넥터 전용입니다. GitHub 커넥터·CLI 경로의 관리자 동의 스크립트(Grant-DefenderAdminConsent.ps1)와는 파일·용도가 다릅니다.

사전 준비

  • 대상 테넌트의 Global Administrator 권한.
  • Azure CLI 설치 및 로그인 (winget install -e --id Microsoft.AzureCLI).
  • 공식 문서에서 Grant-DefenderConsent.ps1 스크립트 전문을 복사해 로컬에 저장.

실행 모드

스크립트는 -TenantId(필수)와 함께 [switch]$ProvisionOnly·[switch]$VerifyToken 스위치로 세 가지 모드를 지원합니다.

모드명령동작
프로비저닝만.\Grant-DefenderConsent.ps1 -TenantId <tenant-guid> -ProvisionOnly로그인 및 서비스 주체 생성만 수행. 동의 부여·토큰 검증은 건너뜀.
프로비저닝 + 동의 (기본값).\Grant-DefenderConsent.ps1 -TenantId <tenant-guid>로그인 → 서비스 주체 생성 → 전역 관리자 동의 부여.
프로비저닝 + 동의 + 토큰 검증.\Grant-DefenderConsent.ps1 -TenantId <tenant-guid> -VerifyToken위 전체 + 토큰 획득으로 동의 검증.
참고 -ProvisionOnly와 -VerifyToken을 동시에 지정하면 -VerifyToken은 무시되며 경고가 표시됩니다.

실행 후 확인

실행이 끝나면 Entra ID > Enterprise applications에서 Microsoft Defender Code가 프로비저닝됐는지 확인한 뒤, Azure DevOps 커넥터 생성을 진행합니다.

주의 이 스크립트는 테넌트 전역 관리자 동의를 부여합니다. 실행 전 반드시 공식 문서에서 스크립트 내용을 검토하세요.
