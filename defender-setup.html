Defender 설정

Defender 포털 쪽 온보딩 — 권한(RBAC)·커스텀 역할 생성과 이니셔티브 진입점을 다룹니다. 전체 설정 단계와 사전 요구사항은 개요를 참고하세요.

권한 및 커스텀 역할 (RBAC)

커스텀 역할 생성 절차

  1. Microsoft Defender 포털 로그인.
  2. 탐색 창에서 System > Permissions.
  3. Microsoft Defender XDR 아래 Roles > Create custom role.
  4. Basics에서 역할 이름·설명 입력.
  5. Choose permissions에서 Agentic code security > AI Scan Security를 확장해 필요한 권한 설정.
  6. Apply → Next로 사용자·데이터 원본 할당 후 Submit.

Defender RBAC 권한 (최소 권한 부여)

Agentic Code Security 권한 그룹 안에서 각 사용자에게 필요한 권한만 부여하세요.

권한용도
Run scan (Manage)On-demand 또는 CLI 스캔 트리거
Upload results (Manage)CLI 스캔 결과를 Defender에 업로드
Scan results (Read)포털·이니셔티브에서 발견 항목 조회
Scan results (Manage)발견 항목 분류·해제·관리

진입점(Entry points)

Defender 포털에서 다음 위치 중 하나로 온보딩 플로우를 시작합니다.

  • Exposure Management > Overview → Agentic code security 선택
  • Exposure Management > Initiatives → Codename MDASH - Agentic code scanner 이니셔티브 선택

온보딩 플로우 — 포털에서 하는 작업

진입점에서 온보딩 플로우를 시작하면 Defender 포털에서는 다음 두 가지를 수행합니다.

  1. 약관 수락 — 온보딩 플로우에서 약관을 검토하고 체크박스로 수락합니다. (수락해야 이후 Save가 활성화됩니다.)
  2. Defender 포털 온보딩 — Foundry 설정에서 복사한 Project endpoint(예: https://your-foundry.azure.com)와 API key를 입력 → Validate로 연결 검증 → Save로 온보딩 완료. (검증에 성공해야 저장할 수 있습니다.)
참고 저장 후 실제 스캔을 실행하려면 GitHub 커넥터(원격, 권장) 또는 Defender CLI 경로를 구성해야 합니다. GitHub 커넥터는 이 온보딩 전후 어느 시점에 만들어도 됩니다.
