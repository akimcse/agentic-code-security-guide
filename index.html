MDASH Private Preview 가이드

Codename MDASH(Agentic 코드 스캐너)는 멀티모델 에이전트 AI 시스템으로 코드 취약점을 기존 정적 분석보다 깊고 정확하게 탐지하는 Microsoft Defender 기능입니다. 현재 프라이빗 프리뷰 단계이며, 이 가이드는 공식 Microsoft Learn 문서를 한글로 정리한 비공식 학습 자료입니다.

Codename MDASH — Agentic 코드 스캐너는 Defender CLI를 확장해 전통적 정적 분석을 넘어서는 에이전트 기반 코드 스캐닝을 제공합니다. 100개 이상의 특화된 AI 에이전트가 여러 LLM에 걸쳐 협업하며 취약점을 찾고, 검증하고, 증명합니다.

주요 기능(Capabilities)

기능설명
AI 기반 취약점 탐지저장소 코드를 멀티모델 에이전트 파이프라인에 제출해 전통적 정적 분석보다 깊이 있게 취약점을 식별합니다.
세분화된 신뢰도 점수각 발견 항목을 UNLIKELY ~ PROVEN의 10단계 신뢰도 체계로 평가해 정밀한 우선순위 지정이 가능합니다.
AI 생성 코드 수정defender fix 명령으로 스캔 결과에서 직접 코드 수정본을 생성·적용합니다.
Defender 포털 중앙 집중발견 항목을 Microsoft Security Exposure Management에 게시해 조직 전체에서 추적·분류합니다.
CI/CD 통합자동화 파이프라인의 일부로 실행되며, GitHub Advanced Security·Azure DevOps 등과 호환되는 SARIF를 출력합니다.

동작 방식 — 다단계 에이전트 파이프라인

특화된 AI 에이전트들이 협업하여 취약점을 찾고, 검증하고, 증명합니다.

  • Prepare(준비) — 콜 그래프 분석과 코드 복잡도 지표로 파일 위험도를 순위화하여, 취약점 가능성이 높은 함수를 우선순위에 둡니다.
  • Scan(스캔) — 100개 이상의 특화 AI 에이전트(예: injection-auditor, memory-safety-auditor, auth-bypass-auditor)가 여러 LLM으로 순위화된 코드를 분석합니다. 각 에이전트는 특정 취약점 클래스를 담당합니다.
  • Validate(검증) — LSP 서버를 통한 taint 분석·타입 해석을 사용하고, 멀티모델 에이전트 토론(debate)으로 신뢰도를 정제하며 오탐을 제거합니다.
  • Dedup(중복 제거) — 중복 발견 항목을 통합해 고유하고 실행 가능한 최종 취약점 집합을 만듭니다.

핵심 특징(Key features)

특징설명
멀티모델 에이전트 아키텍처단일 LLM 프롬프트가 아니라, 여러 모델에 걸쳐 조율되는 100개+ 특화 에이전트.
10단계 신뢰도 체계UNLIKELY ~ PROVEN의 세분화된 신뢰도 점수로 정밀한 우선순위 지정.
통합 리메디에이션defender fix가 스캔 결과에서 AI 기반 코드 수정을 생성.
포털 통합결과가 Microsoft Security Exposure Management에 게시되어 추적·수정.

사전 요구사항 체크리스트

  • Microsoft Entra ID에서 전역 관리자 또는 보안 관리자 역할.
  • 온보딩 중 조직을 대표하여 MDASH 이용 약관을 수락할 권한.
  • MDASH 전용 Microsoft Foundry 리소스를 생성할 Azure 구독·리소스 그룹.
  • 필수 모델을 배포할 권한 (모델 목록은 Microsoft Foundry 연결 > 필수 모델 배포 참조).
  • Foundry 네트워킹이 Selected networks and private endpoints인 경우, MDASH 접근 허용 조치 필요.
  • 다음 AI 스캔 경로 중 최소 하나 (나머지는 나중에 추가 가능): 원격 스캔(GitHub 커넥터, 권장) 또는 Defender CLI.
  • 아웃바운드 제한 시 허용 목록 도메인 허용.
  • Defender 포털에서 Exposure Management·Initiatives를 열 권한, 그리고 Foundry 프로젝트 엔드포인트·API 키.
  • Defender 통합 RBAC 권한 부여 — 아래 권한 할당 단계 참조.

MDASH 프라이빗 프리뷰 전체 과정 (End-to-end)

MDASH 프라이빗 프리뷰는 권한 부여부터 첫 스캔·결과 검토까지 다음 6단계(Step 0–5)로 진행됩니다. 각 단계의 스크린샷과 상세 절차는 연결된 세부 페이지를 참고하세요. (아래 원형 번호가 Step 0–5에 해당합니다.)

  1. 권한 부여 (Assign permissions) — Defender 통합 RBAC로 커스텀 역할을 만들고 Agentic Code Security 권한을 부여합니다. → 권한 설정 (RBAC)
  2. 약관 수락 — 이니셔티브 진입점(Overview 또는 Initiatives)에서 온보딩 플로우를 시작하고 약관을 수락합니다(수락해야 Save 활성화). → 온보딩 시작 (진입점·약관)
  3. Microsoft Foundry 리소스 연결 — 전용 Foundry 리소스를 만들고 필수 모델을 배포합니다. → Foundry 설정
  4. Defender 포털 온보딩 — Project endpoint·API key 입력 → Validate → Save(검증 성공해야 저장 가능). → 온보딩 완료 (엔드포인트·저장)
  5. AI 스캔 설정 — GitHub 커넥터(원격, 권장) 또는 Defender CLI를 구성합니다(이 단계를 마쳐야 스캔이 실행됩니다).
  6. 권장 사항 검토 — 스캔 실행 후 포털·이니셔티브에서 발견 항목을 확인합니다.
