코딩 에이전트에서 사용 — Defender Code Security 스킬

코딩 에이전트를 확장해 MDASH 스캔 결과를 채팅에 표시하고, 로컬 보안 스캔을 인라인으로 실행합니다. 터미널·포털을 벗어나지 않고 최신 발견 확인·스캔·AI 수정까지 수행합니다.

지원: GitHub Copilot CLIClaude

제공 스킬

스킬동작
onboard-defender-cliDefender CLI 바이너리 다운로드 및 테넌트 설정 완료.
run-security-scan현재 저장소의 최신 MDASH AI 스캔 결과를 가져오고, 작업 트리(또는 전체 저장소)에 SAST·SCA·IaC·시크릿 스캔 실행.
fix-security-issues선택한 발견의 diff 미리보기를 생성하고, 수락 시 작업 트리에 수정 적용.

할 수 있는 일

저장소 AI 스캔 결과 가져오기

run-security-scan은 origin 원격에서 저장소를 확인하고 최신 MDASH 발견을 채팅에 반환합니다. 결과에는 브랜치·스캔 타임스탬프·스캔 ID 헤더, 심각도 분포, 발견별 행(심각도·규칙·파일·라인·짧은 근거·Fix it 버튼)이 포함됩니다.

로컬 스캔 및 인라인 수정

로컬 작업 트리에 Defender CLI 스캔을 실행하고, 스캔 범위(변경 파일 또는 전체)·발견·각 항목의 Fix it을 표시합니다. Fix it → fix-security-issues가 diff 미리보기를 게시, 수락 시 작업 트리에 직접 적용됩니다.

로컬 우선 로컬 스캔·수정 과정에서 소스코드는 로컬 머신을 벗어나지 않습니다.

요구 사항

  • GitHub Copilot CLI 또는 Claude CLI 설치 (없으면 aka.ms/copilot).
  • 테넌트에 Agentic 코드 보안 온보딩 완료 (온보딩).
  • Defender 통합 RBAC의 Scan results 권한 Read 수준. 자세한 내용은 Security posture – AI code scan을 참조하세요.
  • 온보딩 중 CLI 바이너리 다운로드용 인터넷 연결.

설치 및 온보딩

GitHub Copilot CLI

copilot plugin install microsoft/security-devops-common:plugin/defender-code-security
참고 경고가 나타나도 무시해도 됩니다. 실제 고객용 설치는 공개 마켓플레이스를 통해 제공될 예정입니다.

Claude CLI

아직 Claude 마켓플레이스에 게시되지 않아 GitHub 소스에서 수동 설치합니다.

  1. onboard-defender-cli 스킬을 github.com/microsoft/security-devops-common/tree/main/plugin/defender-code-security/skills/onboard-defender-cli에서 설치. Claude가 SKILL.md·지원 파일을 가져와 스킬 추가.
  2. 에이전트에게 온보딩 요청 — Onboard me to Defender CLI (Copilot CLI라면 copilot -i /defender-code-security:onboard-defender-cli).
  3. 에이전트가 바이너리를 ~/.mdc에 다운로드, Authenticode 서명 검증 후 PATH에 자동 추가.
  4. 테넌트가 여러 개면 프롬프트에서 선택.
  5. 완료 후 터미널 재시작 또는 AI 스캔된 Git 저장소 폴더에서 Show me AI scan results for my repo로 검증.
