코딩 에이전트에서 사용 — Defender Code Security 스킬

코딩 에이전트를 확장하여 Microsoft Defender 에이전트(Codename MDASH) 스캔 결과를 표시하고, 채팅 안에서 로컬 보안 스캔을 인라인으로 실행합니다. 터미널이나 포털을 벗어나지 않고 최신 발견 항목 확인·스캔·AI 수정 적용까지 수행할 수 있습니다.

지원 에이전트: GitHub Copilot CLI Claude

제공되는 스킬

스킬동작
onboard-defender-cliDefender CLI 바이너리를 다운로드하고 테넌트 설정을 완료합니다.
run-security-scan현재 저장소의 최신 MDASH AI 스캔 결과를 가져오고, Defender CLI로 작업 트리(또는 전체 저장소)에 대해 SAST·SCA·IaC·시크릿 스캔을 실행합니다.
fix-security-issues선택한 발견 항목에 대한 diff 미리보기를 생성하고, 수락 시 작업 트리에 수정을 적용합니다.

할 수 있는 일

저장소 AI 스캔 결과 가져오기

run-security-scan 스킬은 origin 원격에서 저장소를 확인하고 최신 MDASH 발견 항목을 채팅에 반환합니다 — 포털 탐색이 필요 없습니다. 결과에는 브랜치·스캔 타임스탬프·스캔 ID 헤더, 심각도 분포, 그리고 발견 항목별 행(심각도·규칙·파일·라인 번호·짧은 근거·Fix it 버튼)이 포함됩니다.

로컬 스캔 및 인라인 수정

run-security-scan은 로컬 작업 트리에 대해 Defender CLI 스캔을 실행합니다. 스캔된 정확한 범위(변경된 파일 또는 전체 저장소), 심각도·파일 위치별 발견 항목, 각 항목의 Fix it 버튼이 표시됩니다.

Fix it을 선택하면 fix-security-issues가 호출되어 diff 미리보기를 게시합니다. 변경을 수락하거나 거부할 수 있으며, 수락된 diff는 작업 트리에 직접 적용됩니다.

로컬 우선(privacy) 로컬 스캔·수정 과정에서 소스 코드는 로컬 머신을 벗어나지 않습니다.

요구 사항

  • GitHub Copilot CLI 또는 Claude CLI 설치. Copilot CLI가 없다면 aka.ms/copilot에서 설치합니다.
  • 테넌트에 Agentic 코드 보안 온보딩 완료(시작하기 참고).
  • Microsoft Defender 통합 RBAC에서 Scan results 권한 Read 수준.
  • 온보딩 중 Defender CLI 바이너리 다운로드를 위한 인터넷 연결.

설치 및 온보딩

GitHub Copilot CLI 사용

copilot plugin install microsoft/security-devops-commonplugin/defender-code-security
참고 경고 메시지가 나타날 수 있으나 무시해도 됩니다. 실제 고객용 플러그인 설치는 공개 마켓플레이스를 통해 제공될 예정입니다.

Claude CLI 사용

아직 Claude 마켓플레이스에 게시되지 않아, GitHub 소스에서 스킬을 수동 설치합니다.

  1. onboard-defender-cli 스킬을 github.com/microsoft/security-devops-common/…/skills/onboard-defender-cli 경로에서 설치합니다. Claude가 SKILL.md와 지원 파일을 가져와 환경에 스킬을 추가합니다.
  2. 에이전트에게 온보딩을 요청합니다 — 예: Onboard me to Defender CLI. (Copilot CLI라면 터미널에서 copilot -i /defender-code-security:onboard-defender-cli)
  3. 에이전트가 바이너리를 ~/.mdc에 다운로드하고 Authenticode 서명을 검증한 뒤 자동으로 PATH에 추가합니다. 완료를 확인하기만 하면 됩니다.
  4. 테넌트가 여러 개면 프롬프트에서 테넌트 ID를 선택합니다.
  5. 온보딩 완료 후 터미널을 재시작하거나 AI 스캔된 Git 저장소 폴더에서 Show me AI scan results for my repo로 검증합니다. 발견 항목이 심각도·파일 위치·수정 제안과 함께 인라인으로 렌더링됩니다.
